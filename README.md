# playground

Zwei kleine Frontend-Experimente, keine zusammenhängenden Projekte:

- **`glactic/`** — Canvas-Animation eines Sternenfelds/einer Galaxie (Vanilla JS + SCSS)
- **`particles tutorial/`** — TypeScript-Tutorial zu Canvas-Partikelsystemen (`ts/particles.ts`)

Jeweils `index.html` im Browser öffnen.
